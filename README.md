## ⚠️ 重要声明（请务必先读）

> **角色在线查询功能，第三方连接无法对外提供。**
>
> 本插件「在线 / 在线统计」所依赖的在线状态服务为个人搭建的闭源项目
> 非公开服务，**仅追踪单一账号**，无法面向任意角色对外提供在线状态查询。
>
> 因此：
> - 该功能**默认仅供自用**，请勿对外宣称「可查询任意角色在线」
> - 其他人使用时，返回的角色信息可能与自己查询的角色**不一致**
> - 如需正式对外提供，请自行搭建支持任意 `role_id` 的在线查询服务（走推栏接口）
>
> 插件会在角色不一致时给出明确提示，请留意。

> 此后不再更新本插件，不足功能请自行修改

## 功能特点

- **130 个独立功能 / 148 条中文触发词**，覆盖活动日常、名剑排行、物价交易、角色名片、
  奇遇副本、家园社区、塔罗运势、团队管理、本地避雷等场景。
- **多种输出形态**：纯文本、远程图片、HTML/Jinja2 渲染图片、**图文消息链**（图标嵌在文字里）。
- **角色绑定体系**（按用户隔离）：可绑定多个角色，随时查看与解绑，一键统计全部角色在线状态。
- **团队管理**：10 人 / 25 人规格、五人小队、老板标记、报名限制、黑名单、团队本记录。
- **本地避雷**：按会话隔离的骗子/避雷记录，支持添加、删除、查看、查询。
- **实时事件推送**：基于 JX3API WebSocket 的奇遇/玄晶/马场等事件推送。
- **自建本地渲染服务**：插件启动时**自动部署并守护** T2I 服务（自动找 Chromium、自动装
  Playwright、挂了自动拉起、闲置 300 秒自动关浏览器省内存）。
- **AI 生图**：接入豆包（火山方舟）实现文生图 / 图生图。
- **两级缓存**：内存 + SQLite 持久化，减少 API 额度消耗。
- **日志隐私过滤**：聊天正文与调用栈不写入运行日志。

## 安装

### 环境要求

- AstrBot **4.x**（实测 4.29.1）
- Python **3.10+**（实测 3.12）
- 系统需有 Chromium（`/usr/bin/chromium`）；没有的话插件会尝试自动安装

### 安装插件

```bash
cd /path/to/AstrBot/data/plugins
unzip astrbot_plugin_jx3_miemie_*.zip
# 确认目录结构：plugins/astrbot_plugin_jx3_miemie/__init__.py
```

然后到 AstrBot 后台 → 插件 → 重载。

> ⚠️ **务必保留 `__init__.py`**，删掉会导致「加载失败」。

### Python 依赖

```bash
pip install aiohttp aiosqlite pillow jinja2 playwright
playwright install chromium   # 插件也会自动尝试
```

## 新增功能（本次修改）

### 一、角色在线查询（图文消息 ✅）

```
在线 唯我独尊 清唳
```

返回**一条消息**，门派 / 阵营图标直接嵌在文字里：

```
⚪ 离线  ✦ 清唳 ✦
唯我独尊 · 电信区
━━━━━━━━━━━━━━
[天策图标]  门派：天策  Lv.130
🧍 体型：成男
[恶人谷图标]  阵营：恶人谷
📱 手机在线：否
💻 电脑在线：否
🆔 角色ID：31956634
━━━━━━━━━━━━━━
🕐 查询时间：10-25 14:00
```

> ⚠️ 服务返回的角色与查询角色不一致时，会附加提示。

### 二、角色绑定（按用户隔离 ✅）

| 指令 | 说明 |
|---|---|
| `绑定角色 服务器 角色名` | 先校验角色存在，再记录（最多 20 个）|
| `解绑角色 服务器 角色名` | 删除记录 |
| `角色列表` | 查看自己绑定的所有角色 |

**存储位置**：`data/role_bindings.json`（按用户 ID 分开 ✅，重启不丢 ✅）

### 三、在线统计（图片版 ✅）

```
在线统计
```

按绑定列表逐个查询，输出**水墨风格图片**，三分类展示：

- 🟢 **游戏在线**（已登录游戏）
- 🔵 **仅推栏在线**（只登录了手机推栏）
- ⚪ **离线**

每张卡片含：**门派图标 + 角色名 + 区服 · 门派**，底部有使用帮助与时间戳。
背景与「物价」页面保持一致（`/*__INK_CSS__*/` 水墨注入 ✅）。

## 业务流程

### 1. 初始化

```
__init__.py → main.py (Jx3ApiPlugin)
    ↓
构建服务：JX3APIService / JX3BOXService / CacheService / BiLeidata
          TeamManager / EventPushService / ServerBindingService
    ↓
构建 MessageBuilder（130 个指令方法）
    ↓
LocalT2I.bootstrap_background()  → 自动部署渲染服务 ✅
EventPushService.start()         → 实时推送
```

### 2. 指令分发

```
群消息 / 私聊
    ↓
前缀判断 / 免前缀
    ↓
ini_command_map（148 条中文指令 → 方法名）
    ↓
MessageBuilder.xxx(event, *args)
    ↓
① plain_msg      → 纯文本
② T2I_image_msg  → 渲染图片
③ 消息链         → 文字 + 图标
```

### 3. 渲染

```
HTML 模板 + 数据
    ↓
Jinja2 渲染 → 注入 /*__INK_CSS__*/ 水墨 CSS
    ↓
POST http://127.0.0.1:8999/text2img/generate
    ↓
Chromium 截图 → 返回图片路径
    ↓
缓存（大小校验：< 10KB 视为坏图，自动重渲染 ✅）
```

### 4. 缓存

| 层 | 位置 | 说明 |
|---|---|---|
| 内存 LRU | `_cache` | 命中即返回 |
| SQLite | `cache.db` | 持久化，重启可用 |
| 图片 | `cache/images/` | 带坏图自愈 ✅ |

## 注意事项

1. **`__init__.py` 不能删**，否则插件加载失败 ⚠️
2. **在线服务声明**：角色在线查询依赖的个人服务**无法对外提供**（见开头声明）⚠️
3. **API 额度**：JX3API 有每日/每小时限额，建议把 `cache_ttl` 调大到 600 秒以上
4. **角色未收录**：部分角色未进 JX3API 数据库时，资历/名片类功能会返回「未收录」
5. **渲染内存**：Chromium 吃内存，1G 内存的机器建议把 `image_render_quality`
   的 `device_scale_factor` 调到 `0.8`
6. **区服名**：支持别名（唯满侠 → 唯我独尊），写错区服会查不到角色
