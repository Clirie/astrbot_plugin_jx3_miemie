## 三、加新功能：5 种常见场景

### 【场景 1】加一条**纯文字/查询类**指令

**步骤：3 步**

```python
# ① core/message.py 里加一个方法（注意缩进是 4 空格）
    async def wode_gongneng(self, event: AstrMessageEvent, server: str = "", name: str = ""):
        """ 我的功能 服务器 角色 """
        data = await self.jx3api.xxx(server, name)   # 调数据
        if not data:
            yield event.plain_result("⚠️ 查不到")
            return
        yield event.plain_result(f"结果是：{data}")

# ② main.py 的 ini_command_map 里注册（第 310 行那个字典）
            "我的功能": self.jx3cmd.wode_gongneng,

# ③ 后台重载插件 ✅
```

**测试**：私聊发 `我的功能 唯满侠 清唳`

---

### 【场景 2】加一条**出图片**的指令

和数据查询一样，只是返回 `image_result`：

```python
# core/message.py
    async def wode_tupian(self, event: AstrMessageEvent, server: str = "", name: str = ""):
        """ 我的图片 服务器 角色 """
        data = await self.jx3api.xxx(server, name)
        # ① 准备渲染数据
        payload = {"title": "我的页面", "data": data}
        # ② 调渲染引擎（HTML → 图片）
        img = await self.local_t2i.render("wode_tupian", payload)
        # ③ 返回图片
        yield event.image_result(str(img))

# ④ 还要写模板：templates/pages/wode_tupian.html
```

**模板写法**（`templates/pages/wode_tupian.html`）：

```html
{% extends "base.html" %}
{% block content %}
<div class="page">
  <h1>{{ title }}</h1>
  <div class="row">{{ data.name }}</div>
</div>
{% endblock %}
```

### 【场景 3】加一个**AI 生图模板**（最简单 ✅）

**位置**：`core/message.py` 里三张表

```python
# ① _CARD_MENU 加一项（菜单顺序 = 用户回复的序号）
    ("我的风格", "我的风格名"),

# ② _CARD_STYLES 加提示词（键名要和上面完全一致！）
    "我的风格": "描述这个风格的提示词……",
```

**支持的高级写法**：

```python
# A. 自动填充角色门派/体型（写 {force} {body} 就会自动查角色数据）
    "我的风格": "根据【剑网三·{force}(门派){body}(体型)】画一张……",

# B. 自动填充角色名
    "我的风格": "……左侧书写角色名「{name}」……",

# C. 加反向提示词（排除不想要的东西）
    _CARD_NEGATIVE = {
        "我的风格": "低画质，模糊，畸形，水印，多余文字",
    },

# D. 特殊尺寸（如眼睛条 860x340）
    _CARD_EXTRA = {
        "我的风格": ("1536x608", (860, 340)),   # (生成尺寸, 最终尺寸)
    },

# E. 用后处理画字（避免 AI 写错生僻字）
    _OVERLAY_TEMPLATES = ("我的风格",)      # 然后用真实字体画名字/印章
```

**注意**：豆包要求画面 **≥ 921600 像素**，小尺寸要"大图生成 → 压缩" ✅

### 【场景 4】加一个**配置项**

```json
// _conf_schema.json 里加
{
    "wode_peizhi": {
        "type": "string",
        "description": "我的配置项说明",
        "default": "",
        "hint": "填什么填什么"

```

**代码里读取**：

```python
# main.py 的 __init__ 里
self.wode_peizhi = config.get("wode_peizhi", "")

# 或者传到 core 的数据层
self.jx3api = JX3APIService(config, logger, cache)
```

**类型支持**：`string` / `int` / `bool` / `list` / `object`（object 用来分组）

## 四、开发流程（**重要，按这个来** ✅）

```
① 备份（救命工具）
   cp core/message.py core/message.py.bak_$(date +%Y%m%d_%H%M%S)

② 改代码
   · 缩进：类方法 4 空格；这个插件有些 async def 带 2 空格（别动）
   · 别忘 import

③ 语法检查
   python3 -c "import ast; ast.parse(open('core/message.py').read())"

④ 方法数检查（防误删 ✅）
   grep -c "    def \|    async def " core/message.py

⑤ 本地测试（不开机器人测）
   见 tests/ 目录的写法

⑥ 打包 + 重载
   后台 → 插件 → 重载 ✅
```

## 五、几个坑（弟子踩过的 ✅）

| # | 坑 | 后果 | 避免 |
|---|---|---|---|
| 1 | 正则替换范围过大 | **误删 25 个方法** ⚠️ | 先打印匹配范围 ✅ |
| 2 | 键名不一致 | 模板匹配不到 | `_CARD_MENU` ↔ `_CARD_STYLES` 必须一致 ✅ |
| 3 | 改了没重载 | 没反应 | **每次改完必须重载** ✅ |
| 4 | 忘了备份 | 出事难回滚 | 改前先 cp ✅ |
| 5 | 异步方法忘了 await | 报错 | 用 `async def` + `await` ✅ |
| 6 | 配置项没写 schema | 后台看不到 | 同步改 `_conf_schema.json` ✅ |
